- **2026-09-28 — recherche sur une nouvelle localisation : Grove / Tullaghanbrogue (Co. Kilkenny, Irlande)**, point envoyé par capture Google Maps (52.600940, -7.328378). Le point est pile sur le monument SMR KK023-031004 (site à douves) d'un village médiéval déserté enregistré. Même méthode que le dossier d'Armous (histoire, sources, toponymie, inventaire), mais **pas de cibles** : en Irlande la détection d'objets archéologiques sans consentement ministériel est une infraction. Dossier : `docs/zones/grove-kilkenny/`. La zone active de l'app (`config/zone.json`, Meylargues) n'est pas modifiée.
